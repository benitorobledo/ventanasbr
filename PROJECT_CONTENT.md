# 🎯 Contexto del Proyecto: Ventanas BR

## Origen
- **Sitio Actual:** [ventanasbr.cl](https://ventanasbr.cl) (Basado en WordPress).
- **Estado actual:** Landing page de una sola página.
- **Misión:** Clonar la esencia visual pero reconstruir desde cero con tecnología moderna.

## Objetivos de la Migración
1. **Performance:** Pasar de un WordPress lento a un Next.js 14 ultra rápido (Lighthouse +90).
2. **Arquitectura:** Migrar de un constructor visual (Elementor/Divi) a código limpio con **App Router**.
3. **Escalabilidad:** Preparar el sitio para ser desplegado en **Vercel** con SEO optimizado nativamente.
4. **Evolución:** Mantener la estructura visual que el cliente ya conoce, pero expandiendo el contenido de los servicios (descripciones más ricas) para mejorar el posicionamiento orgánico.

## Look & Feel
- Debe sentirse como una evolución premium del sitio actual.
- Mantener la sobriedad del azul marino (#1E3A5F).
- Mejorar la experiencia de usuario (UX) con transiciones suaves entre secciones.
